# Cloud Cargo

Cloud Cargo is an original stationary cargo-allocation practice puzzle. Each manifest presents shared cargo crates and several airship bays. Select a crate and assign it to a bay; all bay mass targets must match, and later manifests require energy totals too. Crates may always be reassigned.

## Controls

- **Keyboard:** Left/Right moves focus across crates and bays. Space selects a crate or assigns the selected crate to a focused bay.
- **Touch:** Tap a crate, then tap an airship bay.

Three deterministic manifests contain 4, 5, then 6 crates. The same seed restarts for mastery, while a normal new visit receives the GameKit seed. Load all three airships before the 50-second limit. Start Loading begins play; Pause and Play Again use the supplied GameKit lifecycle controls.

The game uses only procedural canvas art, has no accounts or network gameplay services, and keeps device-local best score exclusively through GameKit.
