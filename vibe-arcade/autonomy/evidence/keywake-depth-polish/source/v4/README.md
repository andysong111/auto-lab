# Keywake

Keywake is an original deterministic route-planning puzzle. Each seed chooses one of six authored vault packs. In every 4×4 room, collect its colored keys, use their matching gate bars, then enter the exit. Only legal steps count, and only clearing a room earns score.

## Controls

- Arrow keys move one cell; release before repeating that direction.
- Tap the canvas columns labeled LEFT, UP, RIGHT, and DOWN to move on touch devices.
- Start, Pause, Resume, and Replay are provided by the supplied GameKit controls.

The route score compares each completed room against its displayed PAR. Replay uses the same seed, making route order and detour reduction repeatable. The displayed device best is supplied by GameKit device-local practice state. The game uses no accounts, external assets, network services, or sound.
