# Ribbon Shift

Ribbon Shift is an original toroidal-strip spatial puzzle. Restore each three-by-three woven mosaic by cycling a complete row right or a complete column down; every shift wraps around the edge.

Use Left/Right to focus one of six ribbon handles and Space to shift it. On touch screens, tap a board row or its coral arrow to move that row right, or tap a mint arrow below the board to move its column down.

The game uses deterministic seeded boards. The three mosaics have exact shortest solution depths of 2, 3, and 4 shifts, with both row and column moves required in a shortest route. Replay returns to the same deterministic weave. Score and device-local practice best are supplied by GameKit.
