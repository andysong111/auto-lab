## Implemented structure

`schema/`: manifest contract. `orchestrator/`: validated state graph, atomic FileStore/locks, source integrity, repair requests/history, hard/heuristic gate and resumable engine. `gamekit/`: standalone new-game lifecycle, deterministic seed, input adapters, capture, read-only snapshots, local practice best, responsive canvas and error boundary. `qa/`: isolated static server/network guard, Playwright lifecycle runner and timeout worker. `adapters/`: reviewed workspace import, fail-closed isolated command interface, GitHub draft PR / exact-commit Preview / source HTTP smoke. `fixtures/`: original nonproduction test chamber. `tests/`: commissioning and regression.

State flow: IDEA → SPEC_READY → BUILDING → QA_RUNNING → QUALITY_GATE → RC_READY → PREVIEW_DEPLOYING → PREVIEW_SMOKE → READY_TO_SHIP. Failed build/QA/gate → REPAIR_PENDING → REPAIRING → QA_RUNNING. Five unsuccessful repairs → REJECTED. ARCHIVED is terminal. Source tamper/production side effects fail closed. Quality PASS and READY do not enable production.
