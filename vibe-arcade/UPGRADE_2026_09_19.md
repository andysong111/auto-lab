# Scope update — optional login, countries, deeper games and world league

User-approved on 2026-09-19. Guest-first play remains mandatory. No creator marketplace, payments, prizes or chat are approved by this change.

## Live competition structure
- Every player leaderboard renders the self-selected flag immediately beside the public player ID.
- Game → Players: each player’s best server-validated raw score for that game.
- Game → Country standings: top 10 distinct players’ best raw scores per country.
- All ranked games → Players: placement points per game (1st 1000, 2nd 990 … 100th 10) summed across games; raw scores from different games are never added.
- All ranked games → Country standings: top 10 distinct players’ overall championship points per country.
- Players-in-country remains available as a drill-down.
- Only games with a server validator count. Today that is Orbit Sprint; additional games join only after their validator ships.

## First vertical slice
- Original HTML5/canvas game Orbit Sprint: three lanes, jumping low barriers, tall-pillar avoidance, energy pickups, dashing, streak bonuses, 90-second escalating course, local badges/PB.
- Optional Google login and public player ID + optional country/region flag.
- Weekly/all-time world, country and multi-game championship boards.
- Private, namespaced database and server-side input replay verification.
- Public privacy/ranking notice; age-16+ ranked beta and explicit public-profile consent; self-service account deletion.
- Existing three quick-game URLs and their scheduled media remain unchanged.
