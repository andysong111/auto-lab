# Scope update — optional login, countries and a deeper game

User-approved on 2026-09-19. This supersedes the previous temporary no-accounts rule in GOALS/MASTER_PLAN only for this narrow release. Guest-first play remains mandatory. No creator marketplace, payments, prizes, chat or new paid service is approved by this change.

## First vertical slice
- Original HTML5/canvas game `Orbit Sprint` (three lanes, jumping low barriers, tall-pillar avoidance, energy pickups, dashing, streak bonuses, 90-second escalating course, local badges/PB).
- Optional Google login and public player ID + optional country/region flag.
- Weekly/all-time world player board, selected-country player board, country standings.
- Private, namespaced database and server-side input replay verification.
- Public privacy/ranking notice; age-16+ ranked beta and explicit public-profile consent; self-service account deletion.
- Existing three game URLs and their scheduled real-gameplay videos remain unchanged.

## Benchmark evidence (reviewed 2026-09-19)
- Run 3, developer player_03, official Kongregate listing: https://www.kongregate.com/en/games/player_03/run-3 — listed rating 4.3; running/jumping, level progression, infinite mode. Borrow only the learnable movement / mastery / replay loop.
- Canabalt, developer/publisher Finji: https://finji.co/games/canabalt/ — originally Flash, released September 2009; one-button escape, high-score chase and multiple challenge modes. Borrow short attempts and immediate retries, not art, maps, characters or code.
- Bloons TD 5, Ninja Kiwi official Kongregate listing: https://www.kongregate.com/ko/games/ninjakiwi/bloons-td-5 — listed rating 4.6; tower placement, upgrade choices, escalating waves. Candidate for a LATER original strategy prototype, not implemented in this release.

These sources support established game designs, not a prediction that LoopJolt will acquire users or earn money. No global user counts or revenue are assumed. No Flash runtime, ripped assets or copied game source is used.

## Rollout / honest status
Guest Orbit Sprint can be released independently. Rankings return real empty state until players exist. Google Client ID is a required outstanding owner setup, so login and ranked submission remain disabled instead of presenting a fake login.
After setup: test an actual Google account → choose ID/flag → run → verified score → both boards → logout → deletion. Only then call the account/ranking flow end-to-end ready.
