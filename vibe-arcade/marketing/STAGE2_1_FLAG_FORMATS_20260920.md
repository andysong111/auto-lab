# LoopJolt Marketing Stage 2-1 — Flag Competition Formats
Date: 2026-09-20

## Objective
Turn LoopJolt's actual product differentiator — player and country competition — into repeatable short-form content formats.

This stage defines ONLY the content formulas. No video is published from this checkpoint.

## Non-negotiable rules
- Flags are a gameplay/team identity, not decoration.
- Use real flag images, not OS emoji rendering, in produced media.
- Never fabricate players, countries, leaderboard positions, score gaps, rank changes or national matchups.
- When real multi-country data is absent, invite countries to enter instead of pretending a rivalry already exists.
- Keep the rivalry game-like and sports-like. Never insult, stereotype or rank nationalities as people.
- Real gameplay remains the primary footage.
- Every final video must pass the full playback integrity/freeze gate before scheduling.

---

# FORMAT A — FLAG CHALLENGE
## Use when
Default acquisition format while country participation is still sparse.

## Core idea
The viewer is not asked merely to play the game. They are asked to REPRESENT A FLAG.

## Psychological lever
Identity + challenge + unfinished scoreboard.

## First-frame structure
Large real flag tiles around a central challenge line.

Examples:
- WHICH FLAG CLEARS THIS FIRST?
- 48 RINGS. WHICH FLAG FINISHES?
- YOUR RUN COUNTS FOR YOUR FLAG.
- PICK A FLAG. TAKE THE CHALLENGE.

Never show an invented winner.

## 12–18 second structure
0.0–1.0s
- 3–5 large flag images.
- One impossible-looking gameplay frame.
- Hook: WHICH FLAG CLEARS THIS?

1.0–5.0s
- Near-fail / dangerous gameplay.
- Minimal progress label: 31 / 48, BOSS 2 / 3, ONE SHIELD LEFT, etc.
- No fake score.

5.0–10.0s
- Escalation: gate, boss, combo, burst, merge chain, etc.
- Brief label: ONE RUN = ONE COUNTRY SCORE.

10.0–15.0s
- Success or honest failure.
- Transition to product truth:
  PICK YOUR FLAG
  PLAY RANKED
  VERIFIED SCORE -> COUNTRY BOARD

15.0–18.0s
- LOOPJOLT
- PLAY FREE
- URL / LINK IN BIO

## Best games
- Deep Descent: 48 rings / guardians / world changes.
- Core Pins: one-tap precision / near collision.
- Nova Merge: board almost full / chain save.

## Thumbnail formula
- one dramatic gameplay object in center;
- 3–4 actual flag images across top or sides;
- 2–4 word text max:
  WHICH FLAG?
  CLEAR 48?
  ONE RUN.
- no tiny leaderboard screenshot.

## Caption formula
Which flag are you playing for?
[1 sentence describing the challenge]
Pick your flag in LoopJolt. Ranked scores count toward the country leaderboard.
Play free: [link]

## Success metric
Primary: click-through / profile-link taps.
Secondary: comments naming a flag/country, game starts, ranked starts.

# FORMAT B — FLAG VS FLAG
## Use when
ONLY after two or more countries have genuine current-period records for the same game or championship.

## Core idea
Turn existing leaderboard data into a real sports-style matchup.

## Psychological lever
Visible gap + team identity + chance to change the result.

## Required data
- real period (e.g. THIS WEEK);
- real country names/codes;
- real score/points;
- real rank or gap;
- timestamp/snapshot window.

If any of the above is unavailable, fall back to FLAG CHALLENGE.

## First-frame structure
Two large flag images, split screen.

Templates:
- [FLAG A] 8,420  vs  [FLAG B] 8,310
- ONLY 110 POINTS APART
- CAN [FLAG B] TAKE #1?
- [FLAG A] LEADS. FOR NOW.

Use exact live/snapshotted values only.

## 10–16 second structure
0.0–1.5s
- two flags;
- actual score gap;
- period label THIS WEEK.

1.5–6.0s
- gameplay clip from the relevant game;
- show the action that can create points.

6.0–10.0s
- scoreboard cut;
- actual gap again;
- text: EVERY VERIFIED RUN COUNTS.

10.0–14.0s
- CTA:
  PLAY FOR YOUR FLAG
  CHANGE THE BOARD

## Variant ladder
1. #1 vs #2
2. Closest score gap
3. Fastest-rising real country
4. Country trying to enter top 3
5. Same-country player pushing team total

No fake "war", "destroy", "humiliate", nationality insults, or geopolitical framing.

## Thumbnail formula
Left flag / right flag / exact score gap / VS.
Keep only one numeric fact.

## Success metric
Primary: ranked runs from countries shown.
Secondary: repeat visits before weekly reset, comments, leaderboard views.

# FORMAT C — WORLD BOARD
## Use when
At least 3 genuine countries have meaningful current-period records.

## Core idea
The leaderboard itself becomes serialized content.

## Psychological lever
Status + progress + weekly reset + public visibility.

## First-frame templates
- TOP FLAGS THIS WEEK
- WORLD BOARD — 24H LEFT
- 3 COUNTRIES. ONE #1.
- WHO MOVES UP TONIGHT?

## 12–20 second structure
0.0–2.0s
- real Top 3–5 flags;
- actual order;
- visible period label.

2.0–7.0s
- strongest gameplay moment from the game producing the ranking.

7.0–11.0s
- return to board;
- highlight a genuine close gap or new entrant if one exists.

11.0–15.0s
- countdown to weekly reset if technically accurate.
- CTA: PLAY FOR YOUR FLAG.

## Recurring series
- Monday: NEW WEEK. BOARD RESET.
- Midweek: TOP FLAGS SO FAR.
- Final day: 24H LEFT.
- After reset: LAST WEEK'S FINAL BOARD + NEW WEEK START.

Only publish a "final board" after the period is actually closed.

## Thumbnail formula
Top 3 actual flags, rank numbers 1/2/3, WORLD BOARD.
Do not cram full tables into the thumbnail.

## Success metric
Primary: returning ranked users / leaderboard views.
Secondary: shares, comments, country participation breadth.

# Shared creative language

## Preferred verbs
CLEAR
TAKE
CLIMB
DEFEND
REPRESENT
CHASE
BEAT THE SCORE
MOVE UP
ENTER THE BOARD

## Avoid
Generic:
- Play this fun game
- New browser game
- Try LoopJolt

Overclaiming:
- The world is competing
- Korea is beating America
- Millions are playing
- #1 country
unless the corresponding real data supports it.

## Visual grammar
- actual SVG/PNG flag images;
- dark game background;
- large flag blocks;
- one competition fact per shot;
- score/rank numerals large;
- gameplay remains visible;
- LoopJolt gold/lime used as system accent, not flag replacement.

## Country identity hierarchy
1. Flag image
2. Country name / code
3. Score or rank
4. Player handle when useful
5. CTA

This order keeps the national-team concept legible even without sound.

---

# Selection logic
IF fewer than 2 countries have real records:
  use FLAG CHALLENGE.

IF 2+ countries have real records and one pair has a meaningful real gap:
  use FLAG VS FLAG.

IF 3+ countries have real records with a stable ranking snapshot:
  use WORLD BOARD.

Never force FORMAT B or C just because it looks more competitive.

---

# Production gate
Before any of these formats is scheduled:
1. real gameplay source identified;
2. every score/rank/country fact traced to current board data;
3. no fabricated rivalry language;
4. full-file decode passes;
5. full-output freeze scan passes;
6. no unplanned static run >= 0.60s in gameplay body;
7. full 1x local playback watched;
8. start / 25% / 50% / 75% / end inspected;
9. cover frame nonblank and clearly shows flag + challenge;
10. only then schedule via Metricool.

## Stage 2-1 decision
Use FLAG CHALLENGE as the default LoopJolt acquisition format now.
Activate FLAG VS FLAG and WORLD BOARD automatically only when genuine multi-country ranking data exists.
