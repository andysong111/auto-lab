## 촬영 근거

이 브라우저에서는 운영 URL 직접 탐색이 관리자 정책으로 차단되어, 제공받은 동일 빌드의 JavaScript/CSS를 로컬 브라우저 문서에 넣어 실행했다. **운영 사이트에서 직접 녹화한 것이라고 주장하지 않는다.** 운영 Nova Merge 진입 URL의 HTTP 200 응답은 별도로 확인했다. 게임 규칙·시간·점수·성공 상태를 주입하거나 수정하지 않았다. 관측용 래퍼는 원래 규칙 함수를 그대로 한 번 호출하고 결과를 복사한다. 입력 선택용 예측은 별도 복사본만 사용했다.

Core Pins는 일반 Space 입력, Nova Merge는 일반 캔버스 클릭/탭 입력으로 자동 조작했다. 사람이 세운 기록이나 실제 국가에 제출한 기록으로 표시하지 않는다. 모든 외부 네트워크 요청을 차단한 새 브라우저 컨텍스트에서 촬영해 점수 제출·계정 생성·분석 이벤트 전송을 하지 않았다.

두 신규 원본 모두 처음부터 종료까지 녹화했다. 녹화 중 기록한 실제 입력을 원본 규칙 코드에 독립적으로 다시 적용했을 때 **점수뿐 아니라 최종 상태 전체가 일치**했다. Core Pins 27회 입력, Nova Merge 189회 입력이다. Core Pins는 시간 종료 시 3스테이지에 있었으며, 게임 전체를 클리어했다고 주장하지 않는다.

## 실제 편집 구간

**Core Pins:** 첫 1초는 원본 12.50~13.50초의 빽빽한 코어를 보여주는 예고 장면이다. 이후 1~12초는 원본 0.50~11.50초의 시간순 하이라이트다. 두 구간은 겹치지 않으며, 같은 성공을 두 번 한 것처럼 재사용하지 않았다. 원본 약 7.747초의 2스테이지 완료가 출력 약 8.247초에 나타난다. 보스 격파·국가 승리 문구는 없다.

**Nova Merge:** 원본 17.066667~29.066667초를 연속으로 사용했다. 시작 시 여러 열에 7행까지 구슬이 쌓여 있다. 실제 수직 합성·옆 열 연쇄·구슬 제거와 다음 입력을 보여준다. 꽉 찬 열에 넣어도 살아나는 불가능한 장면은 없다. 입력 전후 구슬 수 감소와 계속 진행되는 상태가 원본 증거에 기록되어 있다.

12~18초는 명시적인 그래픽 안내 카드다. 인코딩 경계에서 컷/문구 전환이 한 프레임(약 0.033초) 정도 차이날 수 있다. 원본 플레이를 빠르게 재생하거나 AI 게임 장면으로 대체하지 않았다.

### 작은 움직임의 정지 오탐 처리

초기 넓은 화면/높은 노이즈 허용치(-50/-45 dB) 검사는 두 평면 게임에서 정지 경고를 냈다. 이를 숨기거나 0.60초 기준을 늘리지 않았다. 초기 로그와 실패 결과를 그대로 보관했다.

FFmpeg `freezedetect`는 프레임 성분의 평균 절대 차이를 노이즈 허용치와 비교한다. 기본 허용치는 -60 dB다. 넓은 어두운 배경에서 작은 장애물이나 한 칸의 구슬만 움직이면 평균 차이가 작아질 수 있으므로, 다음 독립 검사로 판정했다.

1. 실제 코어 장애물 영역/구슬 보드 영역의 -60 dB, 0.60초 정지 검사: 비정상 정지 없음.
2. 영상 픽셀에서 Core Pins의 붉은 장애물 위치, Nova Merge의 7×8칸 구슬 색을 추출해 확인: 최대 상태 유지 약 0.033초 / 0.467초로 모두 0.60초 미만.
3. 중간 정지·마지막 게임 구간 정지·게임은 멈추고 헤더만 움직이는 결함을 넣은 QA 전용 영상: **두 게임 × 세 종류 = 여섯 결함 모두 차단.** 이 결함 영상은 배포 패키지에서 제외한다.

FFmpeg 공식 문서: https://ffmpeg.org/ffmpeg-filters.html#freezedetect

따라서 “초기 모든 스캔에서 경고가 전혀 없었다”가 아니라 **오탐을 별도 물체 검사와 결함 주입 시험으로 구분해 최종 파일 검수를 통과했다**는 결과다.

자동 1배속 재생을 사람이 전체 영상을 보고 재미까지 승인한 것으로 표현하지 않는다. 실제 SNS 앱에서 변환된 영상 재생·노출·클릭·재방문 성과는 아직 검증하지 않았다.

## 남겨둔 경계 / 3구간 인계

검토용 마스터·표지·게시글·증거 자료는 준비되었다. 세 파일은 대화 첨부로 전달하며 공개 웹사이트나 SNS에 업로드하지 않았다. 기존 예약 게시물의 정지/재개 상태도 건드리지 않았다.

다음 구간에서는 실제 계정의 프로필 링크와 게임 연결, 플랫폼별 표지 잘림, 추적값을 확인한다. 검수한 파일을 스케줄러에 올렸다면 **호스팅된 복사본도** 다시 검사해야 한다. 공개 발행은 별도 승인 후, 첫 플랫폼 변환본이 제대로 재생되는지 확인한 다음 다른 채널로 확장한다. 제작 완료는 마케팅 성과 입증과 다르다.

새 비용·계정 권한 승인·공개 발행을 제외하면 승준이 지금 고를 기술 항목은 없다.
